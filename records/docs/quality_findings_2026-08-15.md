### A-2. 場面に対して値がありえない — `exam_l5.calculation.Lv2`

### A-3. 設問として破綻 — `g3_l60.calculation.Lv2`

```
435匹のコイを捕まえて印をつけて湖にもどした。数日後に同じ湖で調べたところ、
```

### A-4. 物理的にありえない — `g3_l36.graph_table.Lv2`

### A-5. 分布としてありえない — `g1_l55.calculation.Lv1`

### A-6. 度数分布の形が実在しない — `g1_l55` `g1_l56` `g1_l58.graph_table`

### A-7. 母集団がありえない — `g3_l57.knowledge.Lv2`

## C. 数が教材の数でない（測って確定）

**目視では「不自然に見える」で止まるので、実物 13 出典と並べて数えた**
（道具 `records/work/ref_numbers.py`）。2桁以上の整数の丸さを2つの尺度で見る。

```
                 末尾0率   常用数率
実物 合計（3817個）  34%      61%
私たち 合計（1032個） 37%      62%   ← 一致
```

**集計では一致した。私の目視印象は外れだった。** ところが form で割ると1つだけ外れる。

```
form            末尾0率   常用数率
calculation       26%      62%
graph_table       45%      67%
proof             55%      83%
word_problem      50%      61%
knowledge         12%      41%   ← ここだけ実物から外れている
```

実例:

```
y = -382x² / y = 334x² / y = 411x²      （実物は y = 2x²、y = -3x²）
図形を、点Hを中心として254°回転移動した （実物は 90°・180°）
1本 79 円の品物を x 本買ったとき         （実物は 80円・100円）
「値上がり 449円」を +449円 と表す        （実物は 500円）
(x + 54)(x + 75) を乗法公式を使って展開   （実物は (x+2)(x+3)）
確率が 223/256 であるとき、その余事象     （実物は 1/3・3/5）
```

**原因は1つの `number_domain` を意味の違う量すべてに使い回していること。**
`letter_expr.py` の surface 生成が、道のり(km)・時間・速さ・値段(円)・比例定数・
展開の係数を、family YAML が渡す単一の `int_range` から引いている。
量ごとに自然な粒度（円は10刻み、比例定数は1桁、角度は90°の倍数）が違うのに、
その区別が無い。

**直せる見込みはある。** 対象セルの dup_rate は現状 0.00〜0.12（閾 0.20）で
余裕がある——数を丸めて候補を1/10にしても通る可能性が高い（要実測）。

### G'-3. `ps | grep` で自分の仕事を数えない

テストの終了を待つシェルを2つ立てたら、どちらも**自分自身を検出して永久に待ち続けた**。

```
待ち条件   until ! ps aux | grep -q "[p]ytest"; do sleep 15; done
自分の姿   ... grep -E ... /path/to/pytest.log ...
                              ^^^^^^ ここが [p]ytest に一致する
```

`[p]ytest` の括弧は「自分を除く」ための書き方だが、**コマンドの別の場所に `pytest.log`
という素の文字列がある**と意味を失う。もう1つの待機シェルはそれを見てさらに待った。

★**これは判断も誤らせた。** 途中で `ps aux | grep -c "[p]ytest"` が 2〜3 を返すのを見て
「まだ動いている」と報告したが、数えていたのは待機シェル自身だった。
前のセッションでも同じ形で失敗している（grep が自分のシェルに一致して自分を kill した）。
**プロセス名ではなく PID か、ログの終端行で判定する。**

### G'-4. 斜面も「自由」ではなかった

現実の比例定数を入れる作業の途中で、斜面の a を自由にして **y = 13x² の坂**を出した。
斜面を下る運動は a = (1/2)g·sinθ なので、**自由落下の 5 を超えられない**。
「現実で決まっている量かどうか」は、場面ごとに1つずつ確かめないと分からない。
