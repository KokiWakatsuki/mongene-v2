# 作業ログの置き場

**アカウントを切り替えても続けられるように、ログはリポジトリの中に置く。**
scratchpad（`/private/tmp/claude-501/...`）はセッションごとに消えるので、
そこに置いたログは引き継げない。ここに残す。

## 置くもの

| ファイル | 中身 | 誰が書くか |
|---|---|---|
| `PROGRESS.md` | **作業の逐次ログ**。1行1エントリ（日時・何をしたか・実測値） | 作業のたびに追記 |
| `verify_<日付>_<連番>.log` | 全走（eval/golden/pytest）の生ログ | `verify_all.sh` が書く |
| `measure_<日付>.md` | そのときの実測値の一覧（文型の数・dup・走査の結果） | 節目ごと |

## 規律

- **止まったときに何が分かるかを基準に書く。** 「直した」ではなく
  「g2_l16.Lv2 の文型が 49 → 1 になった（`count_patterns_wp.py`）」と数字を書く
- **利用制限で切れることを前提にする。** 長い処理の前後で `PROGRESS.md` に
  1行書いておけば、次のアカウントは途中から拾える
- 生ログは大きいので、**節目だけコミットする**（毎回コミットしない）
