# 場面として成り立っているか（世界知識の判定）

各問について、**問題文だけ**を読み、下の項目に該当するものがあるかを答える。
**数学として解けるかは見ない**（それは別の検査が見ている）。見るのは
「この文が描いている場面が、現実として成り立っているか」だけ。

## 判定の項目

- **2つの値の関係** — 例: 差が500円しかなく、大人と中学生で区分を分ける意味が無い。実物は2倍前後。
- **品物ごとの相場** — 例: なしは200〜400円台、ももは200〜500円台。品物ごとに相場が違う。
- **場面ごとの相場** — 例: 入園料は数百円〜千円台。買い物の相場（40〜160円）をそのまま使っていた。
- **実在する値の集合** — 例: 180円・290円の切手は実在しない。額面は連続した範囲ではなく**決まった集合**。
- **数の大きさ** — 例: 式としては解けるが、場面としてありえない大きさ（円周角231°・歩いて30km も同型）。
- **語の対** — 例: 館なので入館料。施設名と料金名は対で決まる。

## 書き方

`records/work/wk/verdicts.tsv` に、**全問**について1行ずつ書く。

```
wk-001<TAB>ok
wk-002<TAB>該当<TAB>語の対<TAB>美術館なのに「入園料」（館なら入館料）
```

該当が無ければ 2 列目を `ok` だけにする。該当があれば
`該当<TAB>項目名<TAB>本文のどこがなぜ悪いか` を書く。**1問も飛ばさない。**
